# Каталог схем для бредборда — спецификация для реализации

Каталог уровней для образовательной игры про электронику (Rust + Bevy, солвер поверх ngspice). Один файл — один раздел. В каждом файле: описание каждой схемы, что игрок видит в игре, заметки для реализации и BOM (список деталей), плюс сводная BOM раздела.

Всего схем: **212** в 20 разделах.

## Главное ограничение

Каждая схема должна собираться на настоящем бредборде из деталей, которые продаются в обычных магазинах. Ничего программируемого: никаких микроконтроллеров, EEPROM с прошивкой и модулей, которым нужны команды по шине (I²C, SPI, UART). Готовые модули допустимы, если работают «из коробки» по уровням на выводах (PIR, ИК-приёмник, радиопара с шифратором PT2262/PT2272, ISD1820, MQ-2, HC-SR04, TP4056, ULN2003).

## Безопасность

Только безопасное низкое напряжение: батарейки и адаптеры 5–12 В. Сеть 220 В не используется ни в одной схеме. Схемы с электродами на коже — только от батарей. Лазеры — модули класса 2.

## Базовый набор (не указывается в BOM каждой схемы)

- Бредборд 830 точек — 1 шт. (для больших проектов в BOM отдельно указаны дополнительные платы)
- Набор перемычек папа-папа
- Провода с крокодилами
- Мультиметр — желательно, но не обязателен: в игре есть свой вольтметр и осциллограф

## Обозначения в BOM

- Резисторы — 0,25 Вт, 5 %, если не указано иное.
- Конденсаторы: «керамический» — до 1 мкФ, «электролитический» — полярный, на напряжение не ниже питания, «плёночный» — для таймингов и аналоговых вычислений.
- Для каждой микросхемы 74HC/CD4000 на реальной плате желателен блокирующий конденсатор 100 нФ; там, где он важен для работы, он внесён в BOM явно.
- Номиналы ориентировочные. Перед публикацией уровня схему нужно проверить в солвере и на реальной плате.
- Состав больших проектов (компьютер, пинг-понг, мини-город, часы) — оценка, помечен в заметках.
- «Сложность» — уровень 1–5. В основных уровнях совпадает с разделом, в тематических разделах указана для каждой схемы.
- «Сводная BOM раздела» — максимум каждой детали по разделу, а не сумма.

## Принципиальные схемы (SVG)

Лежат в папке `svg/` и вставлены в файлы разделов. Готовы все 212 схем. В «Найди ошибку» схемы нарисованы парами «как собрано / как надо», неисправный элемент выделен красным, исправление — зелёным. Для сложных проектов (все проекты уровня 5, светомузыка, голос робота, драм-машина, модульный синтезатор, измеритель ёмкости, частотомер, робот с бампером, поворотный стол, тахометр, автономный робот, конечные автоматы из «Аппаратной логики», солнечная станция, эквалайзер, функциональный генератор, цифровой вольтметр, синтез из диодного ПЗУ, измеритель реакции, датчик мышц, сложные световые эффекты, релейные счётчик и сумматоры, аналоговые модели, передача числа по лучу, «Донор», «Сломанный проект», большинство «Задач в игровом мире») дана блок-схема модулей. Синие подписи на схемах (например «RST») — метки цепей: точки с одинаковой меткой соединены. Обозначения: `+9 В` / `+4,5 В` — плюс питания, символ земли — минус. Схемы сгенерированы библиотекой schemdraw и проверены глазами, но перед реализацией уровня их нужно сверить с солвером.

## Машиночитаемая версия

`catalog.json` содержит те же данные: разделы, схемы, уровни, описания, заметки и BOM (`[[название детали, количество], ...]`). Удобно для генерации заготовок уровней.

`catalog.schema.json` is the separate JSON Schema for this reference catalog.
It describes source schematics and BOM metadata only; runnable app projects
continue to use the versioned Project Schema generated by
`bredboard-tools schema project`.

The sibling `../circuits-catalog.html` page presents the same sections with a
client-side search across section text, circuit descriptions, and part names.
